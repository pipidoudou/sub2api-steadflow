# China Models Console

`console/` 是 `China Models` 的后台主项目。

职责范围：

- 用户控制台与管理后台
- 后端 API、认证、订阅、API Key、技能包配置
- 前端后台界面
- Docker / Caddy / 本地部署配置

工作区边界：

- 官网与帮助中心在 `../site`
- 桌面客户端在 `../app`
- 营销内容在 `../marketing`
- 推荐 Skills Pack 源码和打包脚本在 `../skills`

远程仓库：

- `origin` -> `https://github.com/NearZeroOPC/china-models-console.git`
