# China Models Console

`console/` は `China Models` のバックエンド主プロジェクトです。

責務:

- ユーザー向けコンソールと管理画面
- API、認証、サブスクリプション、API Key、Skills Pack 設定
- 管理フロントエンド
- Docker / Caddy / ローカルデプロイ設定

ワークスペース境界:

- 公式サイトとヘルプは `../site`
- デスクトップクライアントは `../app`
- マーケティング資料は `../marketing`
- 推奨 Skills Pack のソースとビルドスクリプトは `../skills`

リモートリポジトリ:

- `origin` -> `https://github.com/NearZeroOPC/china-models-console.git`
